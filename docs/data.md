# Data design and licenses

| Source | Role | License / source |
|---|---|---|
| Original procedural math, mechanics, circuits and pure functions | Train/dev/calibration/test with separate seeds; separate held-out families | Project Apache-2.0; analytic references and hidden tests |
| Reasoning Gym | Reused procedural components and reference design | [Repository](https://github.com/open-thought/reasoning-gym), Apache-2.0 with component notices |
| GSM8K | Official train for training; official test for public evaluation | [Card](https://huggingface.co/datasets/openai/gsm8k), MIT |
| MBPP | Official train only for training | [Card](https://huggingface.co/datasets/google-research-datasets/mbpp), CC-BY-4.0 |
| MBPP+ / EvalPlus | Disjoint evaluation IDs with stronger executable tests | [Repository and notices](https://github.com/evalplus/evalplus); retain upstream task provenance |
| UGPhysics | Eligible English numerical text-only mechanics/electricity, evaluation only | [Card](https://huggingface.co/datasets/UGPhysics/ugphysics), CC-BY-NC-SA-4.0 |

The [frozen manifest](../manifests/data.json) contains configuration hash, public-data flag, file hashes/counts, and per-task ID, split, domain, family, source, license and normalized question hash. It does **not** contain seed, unit, answer type or exclusion fields. Generator seeds are in [data.py](../src/occam_rl/data.py); dataset/model revisions in [revisions.json](../manifests/revisions.json); answers, units, references and tests in the [frozen JSONL artifacts](https://huggingface.co/datasets/BurnyCoder/occam-rl-artifacts/tree/main/frozen-data); rejected candidates and reasons in [preparation logs](https://huggingface.co/datasets/BurnyCoder/occam-rl-artifacts/tree/main/operations). No separate per-task eligibility-decision or generator-version field was saved; generator provenance depends on the recorded source commit. The adapter maps upstream splits explicitly and excludes all official MBPP training IDs from MBPP+ evaluation. Duplicate normalized questions are rejected, including within a split. Tracked runtime logs contain benchmark text; source-specific rights continue to apply.

Procedural numerical references use integer or rational arithmetic. The historical adapter accepted numeric-looking UGPhysics fields, including some incomplete answers. The versioned physics table records the source interpretation, scoring unit, rounding increment and unresolved cases for the entire selected public population. Unresolved references block prospective evaluation of that population. [Rulings](../configs/physics-review.psv) · [Dated amendment](../reports/amendment-004-scoring.md)

The verifier extracts the declared final-answer region and runs code in a resource-limited networkless container. Procedural tests and training MBPP assertions are withheld from policy prompts. Public MBPP+ prompts include worked assertions, often with inputs used in the score. The audit counts matching base and plus occurrences by task. Pinned EvalPlus compares native reference and candidate values for the public subset. Finite tests operationalize correctness on the recorded inputs. [Verifier](../src/occam_rl/verify.py) · [Coverage and reference checks](../results/scientific-audit.json) · [EvalPlus comparison rules](https://github.com/evalplus/evalplus/blob/v0.3.1/evalplus/eval/__init__.py)

The numeric parser accepts finite literals or literal ratios with optional Pint-compatible units. It limits the final-answer string to 256 characters and each scientific-notation exponent to absolute magnitude 1000 before constructing exact fractions. Overflow, zero denominators and malformed units fail verification; unsupported reference syntax is excluded before freezing data. These are parser scope limits, not learned preferences.

The publication rule requires committing the manifest before training. Public dataset/model revisions are pinned. [Independent checks](../reports/independent-fact-check.md) recompute bytes, counts, metadata and overlap. Existing preparation logs supply eligibility/reference-check history; this audit does not claim to reprove every public reference answer. Pretraining contamination cannot be excluded by local split hygiene; public/procedural comparisons remain pending.
