# Independent source verification

Libor “Burny” Burian · 2026-11-19. Earlier project reviews are not evidence for this review. Primary texts, pinned source, current raw records and exact symbolic examples support the decisions below. No new model inference or training was performed. This is a scoped source check, not an exhaustive novelty search or reproduction of external experiments.

Other cited work is checked only to the depth stated; its empirical findings have not been independently reproduced. ## Pinned implementation and model evidence

The [TRL v1.15.0 trainer](https://github.com/huggingface/trl/blob/v1.15.0/trl/trainer/grpo_trainer.py) computes centered group rewards and skips STD division for `scale_rewards="none"`. Its `dr_grpo` loss divides the masked sum by batch size times maximum completion length. [training.py](../src/occam_rl/training.py) selects those options. The upstream implementation is reused; numerical behavior under all future nonzero-reward trajectories remains untested locally. [The documented GRPO interface](https://huggingface.co/docs/trl/grpo_trainer) supports custom rewards and rollout functions.

The [pinned Unsloth loader](https://github.com/unslothai/unsloth/blob/3384411d336a5b43cf81e8fdbf73c010eee08e6b/unsloth/models/loader.py) provides the text-only route selected in [models.py](../src/occam_rl/models.py). [The guide](https://unsloth.ai/docs/models/qwen3.5/fine-tune) supplies model-specific usage context; actual local execution is evidenced by the profile and pilot logs. [Transformers' generation API](https://huggingface.co/docs/transformers/main_classes/text_generation) permits multiple EOS token IDs. [LM Format Enforcer's pinned integration](https://github.com/noamgat/lm-format-enforcer/tree/817f944fcc8851917c40300a47f62d1defc3ffc3) constrains JSON syntax/schema; [Pydantic validation](https://docs.pydantic.dev/latest/concepts/strict_mode/) additionally rejects contradictory adequacy fields. Neither ensures a factually correct judgment.

The [pinned Qwen policy card](https://huggingface.co/Qwen/Qwen3.5-0.8B/blob/2fc06364715b967f1860aea9cf38778875588b17/README.md) documents default non-thinking mode and thinking-loop susceptibility. It does not diagnose this pilot. [Gemma's official E4B GGUF card](https://huggingface.co/google/gemma-4-E4B-it-qat-q4_0-gguf) confirms the model identity and Q4_0 packaging; [frozen revisions](../manifests/revisions.json) select exact candidates. No claim that this is the newest suitable model is established, because suitability/qualification has not been measured. [Pinned llama.cpp server documentation](https://github.com/ggml-org/llama.cpp/blob/ef3848f9d7d4cf7b6b2abfc3b4c960b55d6d9e91/tools/server/README.md) documents the local server interface; the Gemma path remains pending.

The import backport retains the [Apache-licensed upstream implementation](https://github.com/huggingface/transformers/blob/41f9d3992023970fb5a463e70d56232506c80fbc/src/transformers/utils/import_utils.py) and records exact hashes in [runtime-patch.json](../manifests/runtime-patch.json). `uv.lock` records dependency resolution; it does not prove the newest possible compatible set. The Docker build uses a mutable base-image tag, while [runtime.json](../manifests/runtime.json) records the local built image ID. Exact operating-system/image reconstruction is therefore a remaining reproducibility limitation.

Constructed audit arithmetic, elementary physical relations and straightforward Python examples were inspected against their specifications. [Python builtins](https://docs.python.org/3.12/library/functions.html), [integer/list semantics](https://docs.python.org/3.12/library/stdtypes.html), and OpenStax [mechanics](https://openstax.org/books/university-physics-volume-1/pages/1-introduction) and [electricity](https://openstax.org/books/university-physics-volume-2/pages/1-introduction) supply reference context. The initial binary-search omission case does not explicitly state sorted input, even though the supplied code assumes it. “Numbers” in later audit code examples implicitly means ordered real numeric inputs, not arbitrary complex/NaN values. The constructed simplicity preference and adequacy labels are consequently specifications with validity limits, not objective human annotations. Revised audits reuse concepts and problem templates, so fresh wording does not establish statistical independence. Frozen cases and failed results are preserved; future qualification requires a separately justified audit, not a silent repair of these results.

## Evidence/reproducibility checklist application

Following the [NeurIPS checklist](https://neurips.cc/public/guides/PaperChecklist), claims are limited to the supported setting; missing comparisons and failed audits are explicit; seeds, parameters, compute observations, code, data rights and amendments are linked. No inferential confidence interval is attached to the dependent pilot rollouts. The bootstrap is documented with its clustering unit and seed limitations. Reproducibility is incomplete for actual interruption/resumption, the unexecuted Gemma path, worst-case judge context and historical push timing. These are disclosed gaps, not passed checklist items.
